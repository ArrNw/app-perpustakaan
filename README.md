# Sistem Perpustakaan Digital Kampus (app-perpustakaan)

Aplikasi berbasis web yang dibangun menggunakan framework **Laravel 12** untuk mengelola data buku, kategori, anggota perpustakaan, serta pencatatan transaksi peminjaman dan pengembalian buku secara digital.

---

## Cara Menjalankan Project Secara Lokal

1. **Clone repositori dan masuk ke direktori project:**
    ```bash
    git clone https://github.com/ArrNw/app-perpustakaan.git
    cd app-perpustakaan
    git checkout dev
    ```
